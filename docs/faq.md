# AI text watermark FAQ

## How can I detect a Claude text watermark?

You currently cannot verify Claude's model-level text watermark with a public Anthropic detector. Anthropic says detection documentation is forthcoming. This project can find observable Unicode signals, but it will not call those signals a Claude watermark.

## Does the Claude watermark survive copy and paste?

Anthropic says its embedded text watermark travels with copied text and may persist through some editing. The company has not yet released the public detector needed to test a particular passage independently.

## Are Claude watermarks hidden Unicode characters?

Anthropic describes a model-level watermark woven into generated text. Its public documentation does not say that the technique is a sequence of zero-width Unicode characters. A Unicode scan and a statistical watermark test are different operations.

## Does a clean Unicode scan prove text is human-written?

No. A clean scan means the scanner found none of the Unicode signals it checks. It says nothing conclusive about authorship, model use, statistical watermarks, or editing history.

## Does a hidden character prove text was generated by AI?

No. Editors, websites, emoji, typography, languages, and malicious manipulation can all introduce invisible characters. Context and provenance matter.

## Is an AI detector the same as a watermark detector?

No. A general AI detector estimates authorship from learned or statistical patterns. A watermark detector tests for a signal intentionally embedded by a particular system. Their outputs and error modes are different.

## Can this tool remove an AI text watermark?

No. It audits observable signals and compares text versions. It does not claim to remove an unpublished statistical watermark. Removing a visible control character is not evidence that a model-level watermark has been removed.

## Is text uploaded anywhere?

No. The command-line scanner runs locally and has no runtime dependencies or network calls.
