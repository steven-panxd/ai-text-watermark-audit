# Security policy

Please do not open a public issue for a vulnerability that could expose user text, execute untrusted content, or produce a materially misleading provenance result.

Use GitHub's private vulnerability reporting feature when it is available for this repository. Include the affected version, a minimal reproduction, impact, and suggested mitigation.

The project treats bidirectional controls and mixed-script identifiers as review findings because they can be used to disguise text. A finding alone is not evidence of malicious intent.
